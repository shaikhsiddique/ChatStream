![ChatStream Screenshot](https://drive.google.com/uc?export=view&id=1lN6oiCSZfvycMf_z1VqOrmw0ruQ8VW4P)

🚀 **Live Demo:** [ChatStream App](https://chatstream-zyt9.onrender.com/)

## 📌 Overview

**ChatStream** is a real-time, server-side rendered application that allows users to connect with random strangers for live video chatting – inspired by the popular platform Omegle.

Built with:
- 🌐 Node.js & Express.js for the backend
- 🎭 EJS for dynamic frontend templating
- 🔌 Socket.IO for real-time, peer-to-peer communication
- 📹 WebRTC for video streaming functionality

## ⚙️ Features

- ✅ One-on-one random stranger video calls
- ✅ Socket-based room connection
- ✅ Dynamic frontend rendering using EJS
- ✅ Secure and responsive interface

## 🛠️ Tech Stack

| Technology | Description |
|------------|-------------|
| Node.js    | JavaScript runtime |
| Express.js | Web server framework |
| EJS        | Templating engine |
| Socket.IO  | Real-time bi-directional communication |
| WebRTC     | Peer-to-peer video communication |


## 🚀 Installation

```bash
git clone https://github.com/shaikhsiddique/ChatStream.git
cd ChatStream
npm install
npm start
```

Then open `http://localhost:3000` in your browser.
